# Personal Portfolio 🌐

A modern and responsive personal portfolio website to showcase projects, skills, and certifications.  
Deployed on **Netlify** with mobile-first design and reusable components.

![Screenshot_19-8-2025_123923_kishorevanapalli netlify app](https://github.com/user-attachments/assets/5c7aa415-8fba-4cc3-beb8-42b4b991977d)

## ✨ Features
- Fully responsive UI (mobile + desktop)
- Modern design with smooth navigation
- Project showcase with GitHub links
- Easy deployment on Netlify

## 🛠️ Tech Stack
- React.js
- HTML, CSS, JavaScript
- Netlify (hosting)

## 🚀 Getting Started
```bash
git clone https://github.com/KishoreVanapalli/portfolio.git
cd portfolio
npm install
npm start
